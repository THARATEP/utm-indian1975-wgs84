# แปลงพิกัด UTM Indian 1975 ⇄ WGS84 (โซน 47/48)

เว็บแอปไฟล์เดียวสำหรับแปลงค่าพิกัดระหว่างพื้นหลักฐาน **Indian 1975** กับ **WGS84**
ในพื้นที่ประเทศไทย ทั้งโซน 47N และ 48N ใช้งานได้ทั้งบนคอมพิวเตอร์และมือถือ
คำนวณทั้งหมดในเครื่องผู้ใช้ ไม่มีการส่งค่าพิกัดออกไปยังเซิร์ฟเวอร์ใด

## ความสามารถ

- **แปลงสองทิศทาง** Indian 1975 → WGS84 และ WGS84 → Indian 1975
- **รองรับโซน 47N และ 48N** รวมถึงการแปลงข้ามโซน ซึ่งจำเป็นสำหรับพื้นที่คร่อมเส้นแบ่งโซนที่ลองจิจูด 102°E
- **รับค่าที่ป้อนได้ 3 รูปแบบ** พิกัดฉาก UTM (E, N) · ละติจูด/ลองจิจูด (องศาทศนิยม, องศา-ลิปดา-ฟิลิปดา, องศา-ลิปดาทศนิยม) · MGRS
- **แสดงผลครบ** ค่า UTM, ละติจูด/ลองจิจูด และ MGRS ของทั้งสองพื้นหลักฐาน
- **เลือกชุดพารามิเตอร์การแปลงพื้นหลักฐาน** ได้หลายชุด หรือกำหนดเอง 7 พารามิเตอร์
- **แปลงหลายจุดพร้อมกัน** วางข้อมูลหรือนำเข้าไฟล์ CSV และบันทึกผลเป็น CSV
- **ปรับแก้เฉพาะพื้นที่ด้วยหมุดร่วม** (Helmert 4 พารามิเตอร์ หรือ Affine 6 พารามิเตอร์) พร้อมค่าคลาดเคลื่อนตกค้างรายหมุด บันทึกเก็บไว้ในเครื่องหรือเป็นไฟล์ได้
- **แผนที่ภาพถ่ายทางอากาศ** แสดงตำแหน่งค่าเดิมกับค่าที่แปลงแล้ว พร้อมระยะบนพื้นจริง และแสดงตำแหน่งอุปกรณ์แบบติดตามต่อเนื่อง
- **ตรวจความถูกต้องในตัว** เทียบกับค่าอ้างอิงที่คำนวณจาก PROJ และ pygeodesy

## การคำนวณ

- ทรงรี **Everest 1830 (1937 Adjustment)** `a = 6377276.345`, `1/f = 300.8017` สำหรับ Indian 1975
- Transverse Mercator ด้วยอนุกรม **Krüger ลำดับที่ 6** (Karney, 2011)
- การแปลงพื้นหลักฐานผ่านพิกัดฉากศูนย์กลางโลก (ECEF) ด้วย Helmert 7 พารามิเตอร์
  รองรับทั้งอนุสัญญา Position Vector และ Coordinate Frame
- ระยะบนแผนที่คำนวณบนทรงรี WGS84 ด้วยสูตร **Vincenty**

### ผลการตรวจสอบ

ผลลัพธ์ตรงกับไลบรารี PROJ ในระดับต่ำกว่ามิลลิเมตร (48 กรณีทดสอบ ทั้งสองทิศทาง
ทั้งในโซนและข้ามโซน) และค่า MGRS ตรงกับ pygeodesy ทุกจุดทดสอบ
กดแท็บ **ตรวจความถูกต้อง** ในเว็บแอปเพื่อรันการทดสอบบนเครื่องที่ใช้งานจริงได้

## ติดตั้งเป็นแอป (PWA)

เมื่อเปิดผ่านลิงก์ https สามารถติดตั้งเป็นแอปได้ทั้งบน Windows, macOS, Android และ iOS
ติดตั้งแล้วจะมีไอคอนของตัวเอง เปิดเต็มหน้าจอโดยไม่มีแถบที่อยู่เว็บ
และ **การแปลงพิกัดยังใช้ได้แม้ไม่มีอินเทอร์เน็ต** (ส่วนภาพแผนที่ต้องออนไลน์)

- **Windows / macOS** — กดไอคอนติดตั้งท้ายแถบที่อยู่เว็บ หรือปุ่ม “ติดตั้งแอป” ในหน้าเว็บ
- **Android** — Chrome เมนู ⋮ → ติดตั้งแอป หรือปุ่ม “ติดตั้งแอป” ในหน้าเว็บ
- **iPhone / iPad** — Safari ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม

เมื่อมีการอัปเดตเวอร์ชันใหม่ แอปจะขึ้นแถบแจ้งให้กดอัปเดต

## การใช้งาน

เปิดใช้ได้ 3 แบบ

1. **GitHub Pages** เปิดใช้ที่ Settings → Pages → Branch: `main` / `(root)`
   จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
2. **เว็บเซิร์ฟเวอร์ของหน่วยงาน** วางไฟล์ `index.html` ไว้ในโฟลเดอร์เว็บ
3. **เปิดไฟล์ในเครื่อง** ดาวน์โหลด `index.html` แล้วเปิดด้วยเบราว์เซอร์
   (วิธีนี้ติดตั้งเป็นแอปและใช้ GPS ไม่ได้ แต่แปลงพิกัดได้ครบ)

> **หมายเหตุ** การแสดงตำแหน่งอุปกรณ์ (GPS) ใช้ได้เฉพาะเมื่อเปิดผ่าน **https** เท่านั้น
> ตามข้อกำหนดของเบราว์เซอร์ ส่วนการแปลงพิกัดใช้ได้ทุกกรณีรวมถึงตอนออฟไลน์

## ข้อควรทราบ

- การแปลงด้วยค่าพารามิเตอร์ชุดเดียวทั้งประเทศมีความถูกต้องราว 1–5 เมตร
  เนื่องจากโครงข่าย Indian 1975 มีความบิดเบี้ยวต่างกันในแต่ละพื้นที่
  งานที่ต้องการความถูกต้องระดับเซนติเมตรควรใช้การปรับแก้ด้วยหมุดร่วม
- แผนที่ฐานเป็นบริการของผู้ให้บริการภายนอก (Esri, EOX Sentinel-2, OpenTopoMap)
  การใช้งานต้องเป็นไปตามเงื่อนไขของผู้ให้บริการแต่ละราย
